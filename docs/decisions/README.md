# Decisions

One file per workstream (`d2.md`, `g1-fix.md`, ...), written by the builder. Each entry has:

- **Decision**: what was chosen.
- **Why**: the reason, including how the plan was read where it was ambiguous.
- **Alternatives considered**: what was not done.
- **Where in code**: file and function.
- **How to change it**: the concrete edit if the owner decides otherwise.

The owner reviews these. An entry is a builder's reading until the owner confirms or changes it (with a dated owner source); it is not an owner decision.
