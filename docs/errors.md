# Error codes

When a command fails it prints an error code and a run id; Claude reports both. Exit codes: 0 success (held
documents and findings included), 1 finished but some files failed, 2 the command could not run, 3 refused until you
confirm. Every run is logged in `~/FinAnalysis/logs/<date>/<run_id>.jsonl`.
A command-line usage error (a wrong option, argument or value, exit 2) is reported by the parser before a run starts, so it has no error code, run id or log.

| Code | Meaning | What to do |
|---|---|---|
| E001 | A required program (uv, node, quarto), `config.toml` or the audit database is missing, a company has no database ("no database for company <name>": ingest its documents first, `uv run fin ingest <name>`; also for `fin sql`, `statements`, `report` and `review list`), a document the company does not have (Delete on the Files screen), or a program cannot be started | Run the fix `fin doctor` shows (`./install.sh` or `uv run fin init`) |
| E002 | A program is the wrong version, `config.toml` is invalid, or a database was made by an older fin | Run the fix shown (`brew upgrade`, correct `config.toml`, or move the data folder away and run `uv run fin init`) |
| E003 | The data folder is missing or not writable | Run `uv run fin init`, or fix the folder permissions |
| E005 | `fin update` stopped: local changes in this folder, or a git, uv or npm step failed; or the `uv sync` of `fin parser use` failed | Commit or discard local changes, or fix the failing step, and run it again. The backup is in `backups/<run_id>/` |
| E006 | `fin ui`: the web UI add-on is not installed, or its port is in use | Run `uv run fin ui setup` (or `./install.sh`); for a busy port use `--port` |
| E007 | The UI server refused a request: a Host that is not localhost or 127.0.0.1, a missing or wrong token, or a state-changing request that does not come from the UI's own page (Origin) | Open the link `fin ui` printed (it carries the token); do not reach the server through another name |
| E008 | The UI refused a request to change data before it ran: an unknown action, a missing reason, a document id that does not exist, a file that is not held for its unit, a choice or an item a job does not take, a company short code that is not valid or is in use (or an empty name), or an upload that is too large, has an unsafe or unsupported name, or exists already | Fix the request: give the reason, rename the file (.xlsx, .xlsm, .xls or .pdf, plain name), or send fewer or smaller files |
| E009 | The UI chat cannot run Claude Code: `claude` is not installed or cannot start, or it stopped with an error (the message has what it said) | Install Claude Code (https://claude.com/claude-code) and make sure `claude` runs in a terminal; read the message |
| E010 | The UI chat: Claude Code is installed but not logged in | Run `claude` in a terminal once and log in (`/login`) with your own account |
| E011 | The UI chat: a turn of this conversation is still running | Wait for it, or press Stop |
| E012 | An unexpected error: an exception with no error class, which is a defect in fin. The user sees the code, the message and the run id (no traceback); the run log has the traceback and the platform in the event's context | Report the code and the run id; send `logs/<date>/<run_id>.jsonl` |
| E101 | File is unreadable or corrupt, or the path does not exist (the message says where a company's files go: `<data folder>/inbox/<company>/`, lower-case name) | Replace it with a good copy and ingest again. The file is in `review/<company>/` |
| E102 | File is password protected | Save an unprotected copy and ingest that |
| E103 | Unsupported file format | Convert it to `.xlsx` or a text PDF |
| E104 | Scanned PDF (no text layer); fin cannot read it | Get an Excel or text-PDF version, or ask Claude to read the pages |
| E105 | The same file is already loaded | Nothing to do. Use `--force` to load it again as a new version |
| E201 | No tables found in the file | Check the file has statement tables; read the reason in `review/<company>/` |
| E202 | Fiscal periods or column headers not detected | Fix the headers in the file, or ask Claude to read the pages |
| E203 | Unit (crores, lakhs, ...) not detected: a statement sheet or page has no unit line. Ingest holds the file with the question "which unit?" (nothing loaded; fin does not guess); in a reading file, the unit cell names no unit | Ask the user which unit and ingest again with `--unit lakhs\|crores\|millions\|thousands\|rupees` (stored as given by the user), or add a unit line such as "Rs. in Crores" to the file |
| E204 | Parse error while reading the file. A row of values with no label (Excel) names its cells and holds only that sheet: the other sheets load and the sheet is listed as not read; the file fails only when no sheet can be read | Read the reason in `review/<company>/<file>.error.json` (or the sheets not read in the outcome) and fix the file, or ask Claude to read the sheet |
| E205 | A Claude reading file cannot be used (missing columns, unknown statement or scope, bad figure, date or source) | Fix the line named in the message and run again |
| E206 | The PDF add-on (Docling, LiteParse or LlamaParse; the message names it) failed on the pages pdfplumber skipped, could not download its models, or (LlamaParse) found no `LLAMA_CLOUD_API_KEY`; a warning, the pages stay unread | Read the warning in the run log; `uv run fin doctor`; set the key; or ask Claude to read the pages |
| E207 | `fin ingest --unit` was given, but every statement sheet or page of the file names its own unit; nothing loaded | Ingest the file without `--unit` |
| E301 | A line is not in the chart of accounts | Loaded as unconfirmed. Run `/review` to confirm a mapping |
| E302 (warning) | A proposed mapping has low confidence (below 0.7 when proposed); or a bulk `fin review confirm` skipped an item below 0.8. A warning, not an error | Check it in `/review`; confirm a skipped item on its own or with `--each` |
| E303 | A line maps to conflicting accounts | You decide in `/review` |
| E304 | A mapping proposal or review request cannot be applied (unknown account, wrong statement, unknown id or mapping, invalid new account, or a bulk confirm whose every id has confidence below 0.8) | Nothing was applied. Check `/review` and the account name, then retry; confirm a low-confidence item on its own or with `--each` |
| E401-E405 | Findings, not errors: balance sheet (E401), subtotal (E402), cash (E403), documents disagree (E404), unit factor (E405) | The document is held, not rejected. See [Findings](#findings) |
| E406 | A finding to accept does not exist or is not open | Nothing was accepted. Check the ids with `uv run fin findings list <company>` |
| E407 | A figure cannot be stated: unknown account, scope or period, a value that is not a number with at most two decimals, an empty reason, or the account, period and scope already have a stated figure | Nothing was stated. Fix the input; to change a stated figure, withdraw it first (`uv run fin fact unstate <company> <id>`) |
| E408 | A stated figure to withdraw does not exist or is already withdrawn | Nothing changed. Check the ids with `uv run fin fact list <company>` |
| E409 | A figure cannot be corrected: an unknown fact or one of a superseded document, a value that is not a number with at most two decimals, the value it already has, an empty reason, or, inside a diligence engagement, a figure under a query or an adjustment | Nothing was corrected. Fix the input. A difference under a query or an adjustment is the company's: it is queried, never fixed |
| E501 | A database is in use by another `fin` command, or by a background job of `fin ui` | Wait for it to finish and run again |
| E502 | `fin sql` without `--write` was given something other than one SELECT | Use `--write` only for a change you asked for |
| E503 | A database could not be created from its schema file | Report the error |
| E504 | A SQL statement failed (syntax, unknown column, constraint), or `fin sql --write` was given a statement that changes the schema or the session (CREATE, DROP, ALTER, PRAGMA, SET, EXPORT, VACUUM), one that would read a file (`fin sql` runs with file access closed), or one that changes the saved metric tables (`saved_metrics`, `saved_metric_operands`). For an unknown column the message lists the columns of the tables in the query and the question views that have that column | Nothing changed. Fix the statement; `uv run fin schema <company>` lists the views for questions and their columns. Change saved metrics with `fin metric add` and `fin metric remove`. If a company database was changed some other way, restore it from `backups/<run_id>/` |
| E505 | `fin sql --write` was given a statement naming a figure table (`facts`, `raw_values`, `stated_figures`, `fact_corrections`) | Nothing was run. | E506 | `fin metric add`: a name that is not lower-case letters, digits and `_`, a name already used by a built-in or saved metric or an account, a unit other than ratio, rupees or days, an empty definition, or a formula that does not parse or names something that is not an account or a metric; or a new company database whose shared saved metric no longer compiles (the database is not created) | Nothing saved. The message says what is wrong; account names are in `uv run fin map accounts`, metric names in `SELECT metric FROM metric_definitions` |
| E507 | `fin metric remove`: no saved metric of that name (with `--company`, the company's own; without, the shared ones), or another saved metric uses it | Nothing removed. See them with `uv run fin metric list [<company>]`; remove the metrics that use it first |
| E601 | Report render failed | The last good report is kept. Run `uv run fin doctor` (Quarto) and try again |
| E602 | The report narrative contains hand-typed numbers | Replace each listed number with a `{{metric:...}}` or `{{fact:...}}` reference, or reword it |
| E603 | Dashboard build failed | The last good build is kept. Run `uv run fin doctor` (node) and try again |
| E604 | An evidence source file is missing from the archive, cannot be opened, or has no page a figure names | The page is still produced and flags it. Restore the original into `archive/` |
| E701 | The action needs your confirmation | `fin delete` run by hand exits 3 when the typed name does not match; Claude uses `--yes` when you asked |
| E801 | A diligence gate this command needs is not approved: never approved (open), or its data changed since it was approved (reopened) | Nothing changed. See what the gate needs with `uv run fin gate status <company>`; once its checklist passes, you approve it with `uv run fin gate approve <company> <gate>` |
| E802 | A gate cannot be approved: its checklist fails, or an earlier gate is not approved | Nothing approved. Fix the failing checklist lines shown (or approve the earlier gate first), then approve again |
| E803 | No open engagement for the company, or one is already open (`fin query list` and `fin adjust list` say there is none and exit 0 instead) | Open one with `uv run fin engagement open <company> --periods ...`, or close the open one first |
| E804 | An adjustment cannot be proposed: no evidence (query, finding or source), a category not in `config.toml`, a period not in the engagement, an unknown account, effects that do not add up (EBITDA effect not revenue effect minus cost effect), or a reclassification that is not valid | Nothing changed. Add the evidence or correct the value and run again |
| E805 | An unknown query, adjustment or finding id, or a status change that is not allowed | Nothing changed. Check the ids and statuses with `uv run fin query list` or `uv run fin adjust list` |
| E806 | `fin sql --write` was given a statement that writes to a diligence table (`engagement`, `accountant_queries`, `adjustments`, `gate_approvals`, `source_files`, `trial_balance`, `ledger_entries`, `ledger_blocks`, `register_lines`, `bank_statements`, `bank_lines`, `payroll_lines`, `payroll_units`, `ledger_accounts`, `customers`, `recon_runs`, `recon_items`, `recon_match_lines`, `match_proposals`, `passthrough_customers`, `query_items`, `contracts`, `samples`, `sample_lines`, `walkthroughs`, `provision_ledgers`, `inquiries`, `orderbook_lines`, `engagement_rates`, `gst_returns`, `tax_ledgers`, `disclosure_files`, `disclosures`, `related_party_links`, `netdebt_classes`, `netdebt_items`, `fdd_findings`) | Nothing was run.
